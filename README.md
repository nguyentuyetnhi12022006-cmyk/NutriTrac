# 🚀 NutriTrac (Personal Development Project)

> Dự án cá nhân phát triển từ đồ án cuối kỳ môn **Lập trình di động (LTDD)**. Ứng dụng tập trung vào việc theo dõi sức khỏe và quản lý dinh dưỡng mỗi ngày.
---
## 📌 Tổng quan dự án
* **Mục tiêu ban đầu:** Hoàn thành đồ án cuối kỳ môn LTDD (đạt yêu cầu cơ bản của môn học).
* **Mục tiêu dài hạn:** Tiếp tục tối ưu UI/UX, mở rộng thêm các tính năng nâng cao (như nhận diện món ăn, theo dõi calo chi tiết) để làm sản phẩm cá nhân hoàn chỉnh đưa vào portfolio.
* **Trạng thái hiện tại:** Đang trong giai đoạn phát triển và cải tiến các tính năng cốt lõi.
---
## 🛠 Tech Stack (Công nghệ đang dùng)
* **Platform:** Android
* **Ngôn ngữ:** Java / XML
* **IDE:** Android Studio
* **Database:** SQLite
* **Version Control:** Git & GitHub

### 🗓️ Giai đoạn 2: Lộ trình nâng cấp và phát triển tính năng (Đang tiến hành)

#### 1. Tùy chỉnh & Cài đặt Cá nhân hóa
* [ ] **Quản lý mục tiêu:** Cho phép người dùng dễ dàng cập nhật dữ liệu cân nặng hiện tại, thiết lập lại hoặc thay đổi mục tiêu thể hình bất cứ lúc nào.

#### 2. Tùy biến Giao diện & Chủ đề (Themes)
* [ ] Mở rộng khả năng chuyển đổi màu sắc giao diện linh hoạt với các tùy chọn phong cách:
  * Tông màu Tím chủ đạo (Dark Theme mặc định).
  * Chế độ Nền trắng (Light Mode) bảo vệ thị lực theo sở thích người dùng.

#### 3. Trợ lý AI Tư vấn Sức khỏe
* [ ] **AI Chatbox:** Tích hợp hộp thoại chat thông minh hỗ trợ tư vấn 24/7 về chế độ dinh dưỡng, lộ trình giảm/tăng cân và giải đáp thắc mắc sức khỏe cá nhân.

#### 4. AI Phân tích Calo & Định lượng Động
* [ ] **AI nhận diện qua camera:** Tích hợp tính năng chụp ảnh món ăn để AI tự động phân tích và ước lượng hàm lượng calo, sau đó người dùng xác nhận để đưa vào nhật ký.
* [ ] **Định lượng món ăn theo gram:** Cung cấp danh sách món ăn và hoạt động có sẵn với thông số chuẩn, cho phép người dùng kéo thanh trượt chọn số gram tùy ý để lượng calo, protein, carb,... fat tự động tăng hoặc giảm theo thời gian thực.

#### 5. Nhật ký Hình ảnh Tiến trình (Progress Tracking)
* [ ] Xây dựng tính năng lưu trữ hình ảnh luyện tập.
* [ ] Hỗ trợ so sánh trực quan hình ảnh Trước và Sau (Before & After) hoặc ghi nhận các mốc thay đổi trong suốt quá trình thực hiện mục tiêu.
